Proposal: LOINC codes of the microbiology request 'Susceptibility: Phenotypic susceptibility — isolate, not genotyping', computed by ECL over the LOINC Ontology 2026-10-21. Susceptibility of a microbial isolate to a substance, excluding observables that assert a genotyping technique (ECL cardinality [0..0]). Matches the phenotype ValueSet intent (MIC, disk diffusion, gradient strip … any phenotypic method). Parts: LOINC enumeration (1230, LOINC 2.83), LOINC Ontology observables without LOINC code (0), and the ECL as an intensional include. ECL: << 363787002 |Observable entity (observable entity)| : 370130000 |Property (attribute)| = 118588007 |Susceptibility (property) (qualifier value)|, 704327008 |Direct site (attribute)| = << 119303007 |Microbial isolate specimen (specimen)|, [0..0] 246501002 |Technique (attribute)| = << 708060009 |Genotype determination technique (qualifier value)|
