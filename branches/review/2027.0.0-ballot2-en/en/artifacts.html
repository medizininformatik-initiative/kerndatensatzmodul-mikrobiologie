This page provides a list of the FHIR artifacts defined as part of this implementation guide.

Behavior: Capability Statements

The following artifacts define the specific capabilities that different types of systems are expected to have in order to comply with this implementation guide. Systems conforming to this implementation guide are expected to declare conformance to one or more of the following capability statements.

MII CPS Microbiology Metadata

CapabilityStatement for the MII Microbiology module 2027.

Behavior: Search Parameters

These define the properties by which a RESTful server can be searched. They can also be used for sorting and including related resources.

ObservationInterpretation

Search by the interpretation of a microbiological Observation.
mii-sp-mikrobio-interpretation

Search parameter for the norm category of the susceptibility extension
mii-sp-mikrobio-observation-titer

Search by the dilution step of a titre. Indexes the denominator of the Ratio value of MII_PR_Mikrobio_Titer; the numerator is fixed at 1 there. A larger denominator means a higher titre, e.g. ?titer=gt160 finds all titres above 1:160.
mii-sp-mikrobio-observation-triggered-by

Search by the Observation that triggered a microbiological Observation.

Structures: Resource Profiles

These define constraints on FHIR resources for systems conforming to this implementation guide.

MII PR Microbiology Antigen Antibody Quantitative

Quantitative antigen/antibody response describes the quantitative measurement of pathogen-specific antigens or antibodies in a specimen, determined by immunological procedures.
MII PR Microbiology Avidity

Avidity describes the qualitative assessment of the binding strength of antibodies to a specific antigen, typically to distinguish recent from past infections.
MII PR Microbiology Bartlett Score

Bartlett score describes the qualitative microscopic assessment of the suitability of sputum specimens for microbiological culture based on the ratio of inflammatory to epithelial cells.
MII PR Microbiology Colony Count

Colony count describes the quantitative determination of viable microorganisms in a specimen as colony-forming units per volume, per mass or as a count per specimen.
MII PR Microbiology Ct Value

Ct value describes the quantification of the cycle threshold in nucleic acid detection (e.g. real-time PCR) in a specimen.
MII PR Microbiology Diagnostic Report

Microbiological report for summarising and contextualising associated microbiological investigation results.
MII PR Microbiology General Culture

General culture describes the result of an untargeted microbiological culture that checks whether any microorganism grows in the specimen, without restricting the analysis to a predefined pathogen.
MII PR Microbiology General Determination (Identification)

General determination describes the identification of a microorganism or infectious agent in a specimen, without restriction to a predefined target.
MII PR Microbiology General Microscopy

General microscopy describes the morphological observation of microorganisms in a specimen by microscopic examination, optionally with staining techniques (e.g. Gram stain). The result is a morphological group, not a species.
MII PR Microbiology MRGN Class

MRGN class describes the classification of multidrug-resistant Gram-negative pathogens according to the RKI categorisation.
MII PR Microbiology Molecular Pathogen Load

Molecular pathogen load describes the quantitative measurement of the nucleic acid concentration of a pathogen in a specimen, typically as a concentration per volume.
MII PR Microbiology Nugent Score

Nugent score describes a Gram-stain-based semiquantitative scoring system for assessing vaginal microbiota patterns in bacterial vaginosis.
MII PR Microbiology Predicted Susceptibility

Predicted susceptibility describes the expected susceptibility or resistance to antimicrobial substances derived from genotypic resistance detections.
MII PR Microbiology Resistance Category Status

Assessment of a detected pathogen with regard to a defined resistance category, e.g. MRSA, VRE, LRE or LVRE. The assessed category is in Observation.code, the result of the assessment in Observation.value.
MII PR Microbiology Resistance Mechanisms Determinants

Resistance mechanisms / determinants describes the detection of resistance genes, resistance mutations, proteins or functional tests (e.g. CIM test) in a specimen or isolate as an indication of specific resistance mechanisms.
MII PR Microbiology Specific Determination

Specific determination describes the qualitative detection of a predefined microbial target in a specimen by direct molecular, immunological or biochemical detection methods and by detection tests with method-neutral codes. Culture-based targeted detection also belongs here; the procedure is stated in the investigation code and in Observation.method.
MII PR Microbiology Specific Microscopy

Specific microscopy describes the microscopic detection of an object named in the investigation code — such as acid-fast bacilli or leukocytes — with the semiquantitative grade as the result.
MII PR Microbiology Specimen

Specimen describes the material examined microbiologically. The profile derives from the biospecimen base profile of the MII Biobank module and adds the expectations of microbiological diagnostics.
MII PR Microbiology Susceptibility

Susceptibility describes the result of phenotypic resistance testing of a pathogen against antimicrobial substances with reference to an interpretive standard (e.g. EUCAST, CLSI).
MII PR Microbiology Titre

Titre describes a semiquantitative measurement from serial dilution series, reported as a ratio (e.g. 1:160).
MII PR Microbiology Virulence Factor

Virulence factor describes the qualitative detection or exclusion of virulence determinants in a specimen or an isolate.

MII EX Microbiology Susceptibility Norm

Normative susceptibility interpretation metadata (system, version, category).

Terminology: Value Sets

These define sets of codes used by systems conforming to this implementation guide.

MII VS Laboratory Result Semiquantitative

Coding for semi-quantitative laboratory results
MII VS Microbiology Antigen Antibody Method [SNOMED]

Method ValueSet for quantitative antigen and antibody tests and for avidity determination: immunological detection procedures.
MII VS Microbiology Antigen Antibody Quantitative Tests [LOINC]

Test ValueSet for quantitative antigen and antibody tests: LOINC codes for measuring pathogen-specific antigens or antibodies.
MII VS Microbiology Antigen Antibody Quantitative Units [UCUM]

Unit ValueSet for quantitative antigen and antibody tests (UCUM). Bound to Observation.valueQuantity.code.
MII VS Microbiology Avidity Result

Assessment ValueSet for avidity: categorical classification of the avidity index as low, borderline or high. Low avidity indicates a recent infection.
MII VS Microbiology Avidity Tests [LOINC]

Test ValueSet for avidity determination: LOINC codes for avidity tests including the target antigen.
MII VS Microbiology Bartlett Score [LOINC]

Result ValueSet for the Bartlett score: score categories from +3 to -1 that rate the ratio of inflammatory to epithelial cells and thus the suitability of a sputum specimen for culture.
MII VS Microbiology Colony Count Units [UCUM]

Unit ValueSet for colony counting (UCUM): colony-forming units per volume, per mass or as a count per specimen.
MII VS Microbiology Colony Count [LOINC]

Test ValueSet for colony counting: LOINC codes for the quantitative determination of viable microorganisms.
MII VS Microbiology Ct Value [LOINC]

Test ValueSet for the Ct value: LOINC codes with the property cycle threshold in nucleic acid detection.
MII VS Microbiology Culture Result [SNOMED]

Result ValueSet for general and specific culture: growth, no growth or an equivocal result. How much has grown is not stated by this ValueSet but by the colony count. An indeterminable result is represented not via value[x] but via Observation.dataAbsentReason.
MII VS Microbiology Data Absent Reason

Reasons for a missing investigation result. Supplements the FHIR base codes with the indeterminable result that was previously coded via value[x].
MII VS Microbiology Detected Not Detected [SNOMED]

Result ValueSet for targeted qualitative detections: detected or not detected. An indeterminable result is represented not here but via Observation.dataAbsentReason.
MII VS Microbiology General Culture Method [SNOMED]

Method ValueSet for general culture: culture procedures without restriction to a predefined pathogen, including aerobic and anaerobic incubation.
MII VS Microbiology General Culture Tests [LOINC]

Test ValueSet for general culture: LOINC codes for untargeted culture investigation. 11475-1 is preferred because the code names the procedure itself; 41852-5 is equally permitted.
MII VS Microbiology General Determination Method [SNOMED]

Method ValueSet for general determination: non-culture-based procedures for identifying a pathogen without a predefined target, such as microscopy or MALDI-TOF.
MII VS Microbiology General Determination Result [SNOMED]

Result ValueSet for general determination: the identified microorganism, or the negative result if no pathogen was identified.
MII VS Microbiology General Determination Tests [LOINC]

Test ValueSet for general determination: LOINC codes for the untargeted identification of a microorganism. 41852-5 is preferred; the remaining codes are equally permitted where the laboratory names the pathogen group or the sequencing target in the code.
MII VS Microbiology General Microscopy Tests [LOINC]

Test ValueSet for general microscopy: nominal LOINC codes for microscopic observation whose result is the morphology seen. 105059-0 is preferred because it is method-neutral; the codes with a stain in the name (Gram, acid-fast, rhodamine-auramine) are equally permitted and leave Observation.method free in return.
MII VS Microbiology MRGN Class [LOINC]

Result ValueSet for the MRGN classification: 2MRGN, 3MRGN and 4MRGN according to the RKI categorisation. The negative classification is in the module's own CodeSystem, because the LOINC answer list does not carry it.
MII VS Microbiology Microscopy Field of View Units [UCUM]

Units for the count per field of view in the quantity component of microscopy.
MII VS Microbiology Microscopy Semiquantitative [SNOMED]

Quantity ValueSet for microscopy: the semiquantitative grade in which a microscopic finding was seen.
MII VS Microbiology Molecular Diagnostics Units [UCUM]

Unit ValueSet for molecular pathogen load (UCUM): concentration units such as copies per millilitre.
MII VS Microbiology Molecular Pathogen Load Method [SNOMED]

Method ValueSet for molecular pathogen load: amplification procedures for quantifying pathogen nucleic acid.
MII VS Microbiology Molecular Pathogen Load Tests [LOINC]

Test ValueSet for molecular pathogen load: quantitative LOINC codes for the nucleic acid concentration of a pathogen.
MII VS Microbiology Morphology Method [SNOMED]

Method ValueSet for microscopy: the microscopic procedures used. The stain is stated not here but in the extension MII_EX_Mikrobio_Faerbung.
MII VS Microbiology Morphology Result [SNOMED]

Result ValueSet for microscopy: the morphological group observed microscopically, such as Gram-positive cocci in clusters or Gram-negative rods. A species identification does not belong here, even if it was made microscopically.
MII VS Microbiology Organisms [SNOMED CT]

Organism ValueSet: the SNOMED CT hierarchies from which an identified pathogen may come. Not bound directly, but included in the result ValueSets of the determination profiles.
MII VS Microbiology Predicted Susceptibility

Result ValueSet for predicted susceptibility: the predicted category susceptible, intermediate or resistant derived from genotypic detections.
MII VS Microbiology Report Type [LOINC]

Specialised coding of microbiological reports
MII VS Microbiology Resistance Category Status

Investigation codes for assessing a detected pathogen with regard to a defined resistance category.
MII VS Microbiology Resistance Category Status Result

Result of assessing a detected pathogen with regard to the resistance category given in Observation.code.
MII VS Microbiology Resistance Mechanisms Determinants [LOINC]

Test ValueSet for resistance mechanisms and determinants: LOINC codes for the detection of resistance genes, resistance proteins and functional resistance tests.
MII VS Microbiology Resistance Mechanisms Method [SNOMED]

Methods for detecting resistance mechanisms and determinants: molecular, immunological and functional procedures.
MII VS Microbiology Specific Determination Method [SNOMED]

Method ValueSet for specific determination: non-culture-based procedures for targeted pathogen detection, such as amplification, immunoassay or agglutination.
MII VS Microbiology Specific Determination Result [SNOMED]

Result ValueSet for specific determination: detection or exclusion of the target already named in the investigation code, including the grey-zone findings weakly positive and equivocal. An indeterminable result is represented not via value[x] but via Observation.dataAbsentReason.
MII VS Microbiology Specific Determination Tests [LOINC]

Test ValueSet for specific determination.
MII VS Microbiology Specific Microscopy Tests [LOINC]

Test ValueSet for specific microscopy: ordinal LOINC codes in which the object sought and the staining technique are named in the code; the result is the detection, the quantity is in the quantity component.
MII VS Microbiology Staining [SNOMED]

Staining procedures of the microscopic examination, e.g. Gram stain or Kinyoun stain.
MII VS Microbiology Susceptibility

Assessment ValueSet for phenotypic susceptibility testing: the categories susceptible, intermediate, susceptible, increased exposure, resistant and non-susceptible.
MII VS Microbiology Susceptibility Genotype [LOINC]

Test ValueSet for predicted susceptibility: LOINC codes for the predicted efficacy of an antimicrobial substance derived from the genotype.
MII VS Microbiology Susceptibility Method [SNOMED]

Method ValueSet for phenotypic susceptibility testing: the procedures used to measure a minimum inhibitory concentration or an inhibition zone diameter.
MII VS Microbiology Susceptibility Norm

Norm ValueSet for susceptibility testing: the interpretive standard (e.g. EUCAST, CLSI) on whose breakpoints a category is based. Bound to the extension MII_EX_Mikrobio_Empfindlichkeit_Norm.
MII VS Microbiology Susceptibility Phenotype [LOINC]

Test ValueSet for phenotypic susceptibility testing: LOINC codes of the antimicrobial substance tested.
MII VS Microbiology Susceptibility Units [UCUM]

Unit ValueSet for phenotypic susceptibility testing (UCUM): minimum inhibitory concentration in mg/L or inhibition zone diameter in mm.
MII VS Microbiology Titre Method [SNOMED]

Method ValueSet for titre determination: serial dilution procedures.
MII VS Microbiology Titre Tests [LOINC]

Test ValueSet for titre determination: LOINC codes for semiquantitative measurements from dilution series.
MII VS Microbiology Virulence [LOINC]

Test ValueSet for virulence factors: LOINC codes for the detection or exclusion of virulence determinants.

Terminology: Code Systems

These define new code systems used by systems conforming to this implementation guide.

MII CS Microbiology MRGN Result

CodeSystem for results of the MRGN classification that cannot be represented with LOINC. The LOINC answer list LL6195-3 for 99780-9 contains only 2MRGN, 3MRGN and 4MRGN and therefore no negative value.
MII CS Microbiology Resistance Category

Investigation codes (Observation.code) for assessing a detected pathogen with regard to a defined resistance category. Each code names the assessed category; the result of the assessment is in Observation.value.
MII CS Microbiology Susceptibility Norm

CodeSystem for coding the norms used to interpret the susceptibility of microorganisms to antimicrobial substances.

Example: Example Instances

These are example instances that show what data produced and consumed by systems conforming with this implementation guide might look like.

MII EXA Microbiology Antigen Antibody Quantitative

Quantitative antibody determination in serum, using the example of hepatitis B surface antibodies.
MII EXA Microbiology Avidity

Avidity determination of CMV IgG antibodies; the measured value stays in value, the classification is in interpretation.
MII EXA Microbiology Bartlett Score

Bartlett score of a sputum specimen to assess whether it is suitable for culture.
MII EXA Microbiology Colony Count

Colony count as colony-forming units per millilitre.
MII EXA Microbiology Colony Count Catheter Tip

Colony count of a catheter tip in colony-forming units without a denominator. The reference quantity is in Specimen.type.
MII EXA Microbiology Ct Value

Cycle threshold of a real-time PCR for influenza A H3.
MII EXA Microbiology Diagnostic Report

Microbiological report that summarises the associated investigations.
MII EXA Microbiology General Culture

Untargeted culture with growth detected, aerobic culture.
MII EXA Microbiology General Culture Method-Neutral Code

Untargeted culture without growth using the method-neutral investigation code 41852-5: only the method identifies the investigation as a culture.
MII EXA Microbiology General Determination

Untargeted pathogen identification from a specimen, declared as a reflex follow-up investigation of the general culture.
MII EXA Microbiology General Microscopy

Microscopic finding as a morphological group: Gram-positive cocci in clusters.
MII EXA Microbiology General Microscopy Few Gram-Positive Cocci

Gram-stained smear with few Gram-positive cocci: the morphology as the result, the semiquantitative quantity as a component.
MII EXA Microbiology Laboratory

The microbiology laboratory that performs the tests in this module's examples.
MII EXA Microbiology MRGN Class

MRGN classification of a Gram-negative isolate with the result 2MRGN.
MII EXA Microbiology MRGN Class Negative

Identified Gram-negative isolate whose susceptibility results were assessed and which cannot be assigned to any MRGN class.
MII EXA Microbiology Molecular Pathogen Load

Quantitative molecular pathogen load, using the example of CMV DNA in copies per millilitre.
MII EXA Microbiology Nugent Score

Nugent score of a vaginal specimen for assessing bacterial vaginosis.
MII EXA Microbiology Patient

Minimal subject for the examples of this module. No profile, no demographics — Patient is the responsibility of the Person module.
MII EXA Microbiology Predicted Susceptibility

Predicted susceptibility to rifampicin derived from the genotype.
MII EXA Microbiology Resistance Category VRE Negative

Identified Enterococcus without vancomycin resistance: VRE status Negative.
MII EXA Microbiology Resistance Category VRE Positive

Identified Enterococcus faecium with detected vancomycin resistance: VRE status Positive, derived from identification and susceptibility testing.
MII EXA Microbiology Resistance Mechanisms Determinants

Molecular detection of a resistance determinant by PCR.
MII EXA Microbiology Specific Culture

Targeted detection of a predefined pathogen, performed by culture and positive here.
MII EXA Microbiology Specific Culture VRE Negative

Negative VRE test by pathogen-specific culture.
MII EXA Microbiology Specific Determination

Targeted molecular pathogen test with a negative result.
MII EXA Microbiology Specific Determination Influenza Positive

Targeted molecular pathogen detection with a positive result, derived from the reported Ct value.
MII EXA Microbiology Specific Determination VRE Negative

Negative VRE test: the test for vancomycin-resistant enterococci is negative.
MII EXA Microbiology Specific Microscopy Auramine Negative

Auramine stain without detection of acid-fast bacilli: the negative case of specific microscopy.
MII EXA Microbiology Specific Microscopy Kinyoun Two Plus

Kinyoun stain with detection of acid-fast bacilli, with grade two of three as the quantity component — corresponding to 1–10 per field of view.
MII EXA Microbiology Specific Microscopy Leukocytes per Field of View

Leukocytes detected in the Gram-stained smear, with the quantity as a count per high-power field — 10 to 25 — instead of a semiquantitative grade.
MII EXA Microbiology Specimen

Generic specimen material for the examples of this module. The type is deliberately unspecific because the same specimen carries examples of different investigation types.
MII EXA Microbiology Specimen Catheter Tip

Catheter tip as specimen material. It has neither volume nor mass and is therefore itself the reference quantity of the colony count.
MII EXA Microbiology Susceptibility

Phenotypic susceptibility testing with MIC in mg/L; the category with its norm is in interpretation.
MII EXA Microbiology Susceptibility Category Only

Phenotypic susceptibility testing in which only the category is reported and no measured value is available; the norm is in the same place as the category.
MII EXA Microbiology Titre

Titre determination as a dilution ratio, using the example of rubella virus antibodies.
MII EXA Microbiology Virulence Factor

Test for a virulence factor gene with a negative result.
MII EXA Microbiology Workflow VRE 1 Culture Positive

VRE workflow chain, step 1: positive VRE detection by pathogen-specific culture.
MII EXA Microbiology Workflow VRE 2 Identification

VRE workflow chain, step 2: further identification of the isolate as Enterococcus faecium, triggered by the positive detection.
MII EXA Microbiology Workflow VRE 3 Susceptibility

VRE workflow chain, step 3: vancomycin susceptibility testing of the identified isolate with the result resistant.
