The module follows MII calendar versioning. The version published here is
`2027.0.0-ballot.rc1`, the ballot candidate for 2027.0.0; detailed changes are
recorded in the [changelog](changes.html), and how the scheme is expressed as
CRMI metadata is described under [Metadata Overview](metadata.html).

Releases follow the
[Module Release Workflow](https://github.com/medizininformatik-initiative/kerndatensatz-meta/wiki/Module-Release-Workflow).
Beyond that workflow the module has no versioning policy of its own — no support
window for older versions and no separate deprecation rule for profiles.
